# 🚀 NorthPeak Digital

A premium, enterprise-inspired digital agency landing page built with **HTML5, CSS3, and Vanilla JavaScript**. The project showcases modern UI/UX principles, responsive design, accessibility, and frontend performance optimization with a clean, framework-free architecture.

## 🌐 Live Demo

**Website:** https://northpeakdigital-sigma.vercel.app/

---

## 📖 Overview

NorthPeak Digital is a fictional web engineering agency designed to demonstrate modern frontend development skills. The website combines elegant design, smooth interactions, responsive layouts, and performance-focused implementation to deliver a premium user experience.

---

## ✨ Features

- 🎨 Modern enterprise-inspired UI
- 📱 Fully responsive across desktop, tablet, and mobile
- ⚡ Performance-optimized frontend
- 🌙 Glassmorphism design elements
- 📌 Sticky navigation with active section highlighting
- 🎯 Scroll reveal animations using Intersection Observer
- 🖱️ Interactive hero section with subtle mouse parallax
- 💰 Interactive pricing toggle
- ❓ Accessible FAQ accordion
- 📬 Contact form with client-side validation
- 📩 Newsletter subscription section
- ♿ Accessibility-focused semantic HTML
- 🔍 SEO-friendly meta tags and Open Graph support

---

## 🛠️ Tech Stack

- HTML5
- CSS3
- Vanilla JavaScript (ES6)
- Google Fonts
- SVG Icons

## 🚀 Running Locally

Clone the repository:

```bash
git clone https://github.com/AdarshaNaskar/NorthPeakDigital
```

Navigate into the project:

```bash
cd NorthPeak-Digital
```

Open `index.html` in your browser or run it using a local development server such as Live Server or Five Server.
